# 🇰🇷 순천선혜학교 독도교육주간 온라인 포털

> **"아름다운 우리 영토, 독도를 배우고 체험하는 순천선혜학교 독도교육주간 플랫폼"**

순천선혜학교 독도교육주간을 맞이하여 학생들이 우리 영토 독도의 소중함을 쉽고 즐겁게 배울 수 있도록 제작된 온라인 체험 및 교육 포털 웹사이트입니다.

---

## 📌 주요 기능 및 구성

### 1. 🏠 독도 바로 알기 (메인 포털 - `index.html`)
- **맞춤형 독도 교육 콘텐츠**: 특수교육대상 학생들의 눈높이에 맞춘 쉽고 명확한 독도 역사·지리 이야기
- **독도 교육 영상 안내**: 교육용 독도 영상 및 시청각 자료 모아보기
- **체험 대회 바로가기**: 타자 대회 및 사진 퍼즐 대회 원클릭 이동 지원

### 2. ⌨️ '독도는 우리땅' 타자 대회 (`typing.html`)
- **실시간 측정**: 타자 속도(CPM) 및 정확도(%) 실시간 계산
- **감각적 피드백**: 타건 효과음 및 타이핑 인터랙션
- **명예의 전당**: 타자 연습 완료 후 랭킹 등록 및 순위 확인

### 3. 🧩 독도 사진 퍼즐 맞추기 대회 (`puzzle.html`)
- **인터랙티브 퍼즐**: 아름다운 독도 실경 사진을 활용한 퍼즐 맞추기
- **기록 측정**: 완료 시간(초) 및 조각 이동 횟수 카운트
- **퍼즐 랭킹**: 최단 시간 및 최소 이동 기록 경쟁

### 4. 🏆 실시간 랭킹 시스템 (`ranking.js`)
- 학생별 성취도 고취를 위한 로컬/실시간 랭킹 관리
- 대회 참가자 명단 및 명예의 전당 제공

---

## 🛠 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla JavaScript (ES6+)
- **Styling**: Vanilla CSS (Pretendard & 나눔명조 폰트, Glassmorphism, 다크 모드 테마)
- **Dependencies**: 무설치 순수 웹 표준(Zero External Framework Dependency)

## 🚀 실행 방법 (Getting Started)

별도의 패키지 설치나 빌드 과정 없이, 웹 브라우저에서 바로 실행할 수 있습니다.

1. 저장소를 클론(Clone)합니다:
   ```bash
   git clone https://github.com/joeyKor/dokdo.git
   cd dokdo
   ```
2. `index.html` 파일을 더블 클릭하거나 웹 브라우저(Chrome, Edge 등)로 엽니다.
   - 로컬 웹 서버(VS Code Live Server 등)를 이용하시면 더욱 쾌적하게 이용하실 수 있습니다.
